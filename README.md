# 🍽️ Restaurant Web Application (https://antopolis-client-three.vercel.app/)

This is a responsive and modern restaurant web application built using **Next.js** on the frontend and **Node.js**, **Express.js**, **MongoDB**, and **Mongoose** on the backend.

---

## 🚀 Features

### Frontend (Next.js)
- Modern responsive UI with Tailwind CSS
- Smooth animations with Framer Motion
- Google Fonts integration (Poppins)
- Reusable components: Hero, Products, Feedback, Members, Footer
- Toast notifications using `sonner`
- Optimized image rendering with `next/image`

### Backend (Node.js + Express.js + MongoDB)
- REST API built with Express
- MongoDB with Mongoose for data modeling
- Secure API architecture
- Handles product listing, customer feedback, user/member data, etc.
